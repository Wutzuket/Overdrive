# Kohlekraftwerk

Das Kohlekraftwerk ist der kleine Startgenerator von Overdrive. Es verbrennt
Brennstoff wie ein Vanilla-Ofen und schiebt die Energie in die Nachbarblöcke.

<BlockImage id="overdrive:coal_generator" scale="2" />

## Betrieb

| Eigenschaft | Wert |
|---|---|
| Energiespeicher | 400.000 FE |
| Ausgabe | 20 FE/t |
| Brennstoffslots | 1 |
| Automatisch pushen | ja (konfigurierbar) |

Weitere Brennstoffe lassen sich in der gemeinsamen Konfiguration eintragen. Das
Kraftwerk verbrennt jeden Brennstoff, den auch ein Vanilla-Ofen verbrennen
würde.
