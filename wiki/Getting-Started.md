# Getting Started

## Installation

1. Install Minecraft 1.21.1.
2. Install a compatible NeoForge 21.1.x profile.
3. Install Java 21.
4. Download the Overdrive JAR and place it in the `mods` folder.
5. Launch the game with NeoForge.

JEI is strongly recommended because Overdrive contains many machines and
processing chains. The One Probe and Connected Textures Mod can be installed
for optional integration features.

## Progression

Overdrive is built around progressively more complex technology:

1. Gather the required ores and basic components.
2. Build the early processing and energy infrastructure.
3. Assemble multiblock machines for particle, fluid and antimatter processing.
4. Add cooling and cryogenic systems to control heat and process advanced
   fluids.
5. Use the scanner and JEI to discover multiblock components and recipes.
6. Build an antimatter annihilation setup for high-end energy production.

The exact recipes and processing values are available in JEI in-game.

The Circuit Press is an early machine for producing circuit boards and other
electronic components. It is crafted in a crafting table, requires FE, and can
use up to four inputs for each processing recipe. See the
[Circuit Press](Circuit-Press) page for its recipe and configuration options.

## Multiblock machines

Many advanced systems use multiblock structures. Place the correct casing,
controller, ports and internal components according to the relevant recipe.
Use the Overdrive scanner to inspect supported components and structure
recipes. A wrench can be used with blocks that are marked as wrenchable.

## Fluids and safety

Advanced fluids such as cryofluid, steam, liquid iridium and antimatter-related
fluids are used throughout the processing chains. Plan dedicated input and
output lines for each machine and provide appropriate cooling before increasing
production.
